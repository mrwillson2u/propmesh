Once a board runs PropMesh, updates reach it over the mesh from the console. You shouldn't need to plug it in again.

<Steps>

1. In **Nodes & Channels**, open the **↑ Firmware** chip and choose **Over the mesh**.

2. Leave **Image** on **Latest release**. The console loads the newest PropMesh firmware from this site by itself and shows **✓ latest release · build …**. Each board type gets its own version automatically.

3. Press **Update all mesh boards**, or **Update** on one board. Each board takes a few minutes, and the table shows how far along it is and which boards are already **up to date**.

4. Update the bridge, which is the board your console is connected to, **last**, with **Update (last)**.

</Steps>

<Aside title="Safe to interrupt">
If an update stops partway because a board loses power or you close the laptop, the board shows **paused**, and **Update** resumes it. A board that can't start the new firmware rolls back to the old one on its own.
</Aside>

The computer running the console needs internet access to load the release. The boards don't.

## Your own build

If you built the firmware yourself, choose **My own build**. Then either pick the `.bin` file with **from file**, or run `python3 tools/ota_serve.py --build` and paste the address it prints.

**Over WiFi** is the faster option when your boards are in range of your home WiFi. Each board joins the network and downloads the update itself. The boards can only download from a server on your own network, so this always needs `tools/ota_serve.py`, which is covered in the project's developer notes.
