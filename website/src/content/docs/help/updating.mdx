Once a board runs PropMesh, you never need to plug it in again: updates travel over the mesh from the console.

<Steps>

1. In **Nodes & Channels**, open the **↑ Firmware** chip and choose **Over the mesh**.

2. Leave **Image** on **Latest release**. The console loads the newest PropMesh firmware from this site by itself and shows **✓ latest release · build …**. Each board type gets its own version automatically.

3. Press **Update all mesh boards**, or **Update** on one board. Each board takes about six minutes; the table shows how far along it is and which boards are already **up to date**.

4. Update the bridge — the board your console is connected to — **last**, with **Update (last)**.

</Steps>

<Aside title="Safe to interrupt">
If an update stops partway (a board loses power, you close the laptop), it shows **paused** — **Update** resumes it. A board that can't start the new firmware rolls back to the old one on its own.
</Aside>

The computer running the console needs internet access to load the release; the boards don't.

## Your own build

Built the firmware yourself? Choose **My own build**, then either pick the `.bin` file with **from file**, or run `python3 tools/ota_serve.py --build` and paste the address it prints.

**Over WiFi** is the faster option when your boards are in range of your home WiFi: each board joins it and downloads the update itself. The boards can only download from a server on your own network, so this always uses `tools/ota_serve.py` — see the project's developer notes.
