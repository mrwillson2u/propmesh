## What you can build

<CardGrid>
	<Card title="Props that react" icon="rocket">
		A motion sensor sees someone coming. A skull's eyes light up, a coffin lid rattles and the fog machine starts, each on its own board, all on the same cue.
	</Card>
	<Card title="Lights that set the mood" icon="star">
		LED strips with a flickering fire effect, dimmable lanterns and inexpensive Bluetooth flood lights, all run from the same show.
	</Card>
	<Card title="A show that runs itself" icon="seti:clock">
		Set it to come on at dusk and go quiet at bedtime. There is a **STOP ALL** button for when you need everything off right now.
	</Card>
	<Card title="No wires between props" icon="random">
		Boards pass messages along to each other, so a prop in the far corner of the yard works even where your WiFi doesn't reach.
	</Card>
</CardGrid>

## What you need

- **ESP32 boards**, about $5 to $10 each. [Which one?](/propmesh/boards/)
- **A computer with Chrome or Edge** for setup. Everything happens in a web page, so there is nothing to install.
- Whatever your props already use: servos, LED strips, relays, motion sensors.

You don't need to solder to get started, and you don't need to write any code.
