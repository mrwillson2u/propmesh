PropMesh is free, open source, and built for the home-haunt and holiday-display community. You don't need to write code to help.

## Ways to help

- **Tell us what happened.** Bugs, confusing screens, something this site got wrong: [open an issue](https://github.com/mrwillson2u/propmesh/issues). Photos and screenshots are gold.
- **Show your props.** How you wired a jaw, which flood lights paired, what your schedule looks like — that's exactly what the next person needs.
- **Improve these docs.** Every page has an **Edit page** link at the bottom. Fix a typo or add a tip right on GitHub.
- **Add a board.** A board works with PropMesh once it has a *profile*: a short file listing what each pin can do. Copy one from [`boards/`](https://github.com/mrwillson2u/propmesh/tree/dev/boards), fill it in from the seller's pinout, and send it in — its page on this site is made from that file.
- **Write code.** The firmware (ESP32, PlatformIO) and the console (React, TypeScript) live in the same repository.

## How changes come in

Changes go to GitHub as pull requests into the **`dev`** branch. Read [`CONTRIBUTING.md`](https://github.com/mrwillson2u/propmesh/blob/dev/CONTRIBUTING.md) first — it's short — including the sign-off line each commit needs.
