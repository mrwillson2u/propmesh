A sensor is how the yard knows someone is there. Anything that switches a wire on or off works.

| Sensor | Good for | Notes |
|---|---|---|
| **PIR motion** (HC-SR501, AM312) | "someone walked up" | needs ~1 minute to settle after power-up; the knobs on an HC-SR501 set range and how long it stays on |
| **Pressure mat** | "someone stepped *here*" | a switch: wire like a button |
| **Break-beam** (IR or laser) | "someone crossed the path" | precise and fast — good for a hallway |
| **Button** | a manual "go" | wire between a pin and GND |

## Wiring

**Sensors with their own output** (PIR, beam receivers): power, ground, and their **OUT** to a board pin. In the console set **pull** to **none** — the sensor drives the pin itself.

**Switches** (buttons, pressure mats, reed switches): one wire to the pin, the other to **GND**. Set **pull** to **up** and tick **active = LOW** — the pin reads "on" when the switch connects it to ground.

<Aside type="tip" title="Which pin?">
Some pins can only be inputs (on the DevKit V1: VP, VN, D34, D35). Use those for sensors and keep the others free for outputs. But those four have no internal pull-up, so a **button** there needs an extra resistor — put buttons on a pin that has a pull-up instead. The board pages list which is which.
</Aside>

## In the console

Assign the pin to **Sensor / button input**, set **pull** and **active = LOW** as above, and **Save to node**. The TEST column shows **● ACTIVE** or **○ clear** live — walk past, step on the mat, press the button, and watch it change.

Then make it do something: [Triggers](/propmesh/show/triggers/).

<Aside title="On a battery board">
A battery prop sleeps when the show is off, and only some pins can wake it. Put its sensor on one of those — the console warns you if you don't. See [Battery props](/propmesh/props/battery/).
</Aside>
