Every board needs the PropMesh firmware installed once, over USB. After that, updates go out over the air from the console.

<Aside type="note" title="Beta firmware">
This is the firmware the project runs on its own yard, but it is beta software and it changes often. Installing it replaces whatever the board was running before. The in-browser installer below is new as well. If it gives you trouble, the PlatformIO route at the bottom of this page is the fallback.
</Aside>

<Flasher />

When you press **Install PropMesh**, the browser asks which USB device to use. Pick the one that appears when you plug the board in. It is often named **CP210x**, **CH340** or **USB JTAG/serial**. Installing takes about a minute.

When it finishes, the installer shows a small menu for the board that is still plugged in. **Install PropMesh for …** there means install it *again* on this same board, which you don't need. **Logs & Console** shows the board's own log live in the browser, handy if something isn't working. Close the menu with the **×**, press **RESET** on a C3 or C6, and [connect to the board from the console](/propmesh/start/first-scare/#3-connect-the-console).

<Aside type="caution" title="Erase or keep?">
The installer may offer to erase the board first. On a board that has never run PropMesh, erase it. On a board that already runs PropMesh, skip the erase so it keeps its name and pin setup.
</Aside>

## If it doesn't work

**No device shows up in the list, or it keeps appearing and disappearing.** A port that comes and goes is the board's current firmware restarting over and over, which is common on a brand-new C3 or C6 with its factory demo program. Put the board in install mode by hand (below) and it holds still.
- Try another USB cable. Many cables only carry power.
- Some boards need a USB driver on Windows or on older versions of macOS. Which one depends on the chip next to the USB socket: the **CP210x** driver from Silicon Labs or the **CH340** driver from WCH.
- Close anything else that might be using the board, such as the Arduino IDE's serial monitor or another console tab.

**It starts, then fails to connect, or says "Failed to initialize."** The board isn't in install mode. On a DevKit or Feather: hold **BOOT**, press and release **EN** (or **RST**), let go of BOOT, and press Install again. On a C3 or C6 SuperMini, whose USB port is part of the chip, the installer can't restart it for you: unplug it, hold **BOOT** while plugging it in, then press Install and pick the port that just appeared. After installing, press **RESET** to start the new firmware. The steps show above the Install button when one of those boards is selected. On a C6 SuperMini the BOOT trick only works some of the time, because the chip also reads pin 8 as it starts and nothing on the board holds that pin either way. Touch a jumper wire from pin **8** to **3V3** while you hold BOOT and plug in, and it works every time. If an LED next to the USB socket lights as you plug it in, that attempt didn't take: unplug and try again with the jumper.

**The page says this browser isn't supported.** The installer needs **Chrome** or **Edge** on a desktop or laptop. Safari, Firefox and phone browsers can't talk to USB devices.

<Aside title="Building it yourself">
If you prefer PlatformIO, the firmware is in [`firmware/node`](https://github.com/mrwillson2u/propmesh/tree/dev/firmware/node). Run `pio run -e esp32-devkit-v1 -t upload`, using the board id from its page under [Boards](/propmesh/boards/).
</Aside>
